# 现场验收记录

此文档是未完成实机项目的操作步骤，不是已经通过的结果。每台设备分别填写，不用手机投屏成功替代 Mac 发送端测试。

## 环境

记录日期、Mac 型号、macOS build、Claw4/Tab5 硬件批次与面板、P4 chip revision、P4 源码 SHA256、C5/C6 固件版本、AP 型号/频段和网络隔离设置。确认与 P4 revision 匹配的镜像；保存原厂可恢复固件。

## 验收顺序

1. **上电与屏幕。** 串口显示实际 P4 revision、PSRAM 32 MB；面板色彩与背光正常；软键盘每个区域与手指位置一致。失败时只定位板级初始化。
2. **配网。** 启动设置 AP，输入错误密码时能回到配网；正确配置后显示 LAN IP；重启后保留设置。Tab5 先用 2.4 GHz。
3. **BLE。** `PAIR` 后在 Mac 系统蓝牙中连接。记录 C5/C6 是否启用了 BT controller、HID 加密/订阅状态。`INPUT READY` 才做键鼠测试。
4. **发现。** Mac 原生屏幕镜像菜单能看到设备。此时仅标“发现通过”，不要标“投屏通过”。
5. **握手与视频。** 保存 RTSP阶段、FairPlay mode、timing/镜像连接日志；必须实际收到 SPS/PPS/IDR。`NO_VIDEO` 时停止本阶段，不把黑屏或静态欢迎图当作镜像。
6. **物理画面。** 播放自制秒表或滚动文本。记录实际 SPS profile/level/宽高、解码帧数、显示提交、丢弃 AU、PSRAM 最低值、平均/最差延迟。只用本地秒表对照判断端到端延迟。
7. **镜像与扩展。** 分别选择系统提供的两种模式。把测试窗口移到扩展屏，确认两块显示器显示不同内容，记录菜单是否实际提供扩展选项。
8. **键盘。** TextEdit 中测试全部字母/数字/标点、Shift、Ctrl、Opt、Cmd、组合键、Delete 长按、方向键、中文输入与候选。重连后没有粘键。
9. **触控。** 点击、长按拖动、双指滚动、右键；检查指针移到扩展屏的可用性。若启用绝对模式，记录每块屏幕排列下四角和中心实际命中情况。不能仅记录报告坐标。
10. **连续会话。** 至少 30 分钟静止/滚动/键盘混合操作；停止镜像、切换网络、断开 BLE、再次连接；记录温度、堆内存和错误。没有依据时不要写 720p30 或某个延迟指标。

## 状态判定

| 观测 | 可以判定 | 下一步 |
| --- | --- | --- |
| 菜单出现设备 | Bonjour 发现成功 | 配对和视频 |
| RTSP 200 / TCP accepted | 控制/传输已建连 | 检查 SPS/PPS/IDR |
| STREAMING | 已产生有效压缩 AU | 检查解码/显示 |
| 解码帧数增加 | 软件生成了像素 | 看物理屏幕动态画面 |
| LCD 提交返回成功 | 驱动完成了对应传输边界 | 实物观察颜色、撕裂与触控 |
| 扩展屏真实动态画面 + HID 操作 | 当前环境基本链路通过 | 持续性能与恢复测试 |

本次交付没有这两块实物和真实 Mac 会话的观测，不能替用户预先勾选通过。
